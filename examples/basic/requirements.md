# 排序与二分查找实验

这是一组专为本仓库编写的公开演示材料，不是真实课程作业或学生信息。

## 实验目的

理解插入排序的循环不变式和二分查找的边界处理，使用 Python 实现并解释算法。

## 任务1 插入排序

1. 实现返回升序新列表的 `insertion_sort(values)`，不得修改原列表。
2. 测试普通输入 `[5, 2, 4, 2]`、空列表 `[]`、单元素 `[7]`。
3. 报告包含设计思路、关键代码、输入输出、时间与额外空间复杂度分析。

## 任务2 二分查找

1. 实现 `binary_search(values, target)`，输入是已升序排列的列表；找到时返回下标，找不到返回 -1。
2. 对列表 `[1, 3, 5, 7, 9]` 分别查找 7 和 4，并测试空列表。
3. 报告包含边界更新方式、输入输出和复杂度分析。不要求重复值的最左下标。
